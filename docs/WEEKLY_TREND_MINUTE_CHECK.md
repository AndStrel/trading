# Недельный тренд: фиксированная сверка исполнения по минутам

Правила этой сверки записаны до расчёта. Исходный сигнал, выбранные недели, даты входа и выхода берутся без изменений из `.trading/weekly-trend-v1.json`. Сверяются только сделки с датой входа 2023–2025, когда локально есть сверенные минутные архивы SBER.

Для каждой сделки вместо дневного `open` использовать `open` свечи ровно 10:05 МСК в её исходные даты входа и выхода. Если одной минуты нет, пометить сделку `missing-execution-minute` и исключить из расчёта парных метрик; соседнюю свечу не подставлять. Доходность считать теми же затратами: комиссия 0,3% и проскальзывание 0,05% на сторону, стресс 0,10%. Ни даты, ни сигналы, ни лимит позиций по результату не меняются.

Показать количество сопоставленных и пропущенных сделок, долю net-прибыльных, средний net, profit factor, результат без пяти лучших сделок и расхождение с дневной моделью. Это проверка чувствительности к модели исполнения, **не** новая торговая стратегия и не независимый holdout. 2026 не используется.
