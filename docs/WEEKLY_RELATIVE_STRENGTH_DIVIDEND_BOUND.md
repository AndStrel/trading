# Дивиденды: верхняя оценка для слабых лет relative-strength-v1

Метод зафиксирован до пересчёта. Это не изменение сигнала или сделок: используется полный журнал `.trading/weekly-relative-strength-v1.json` без исключения проигрышей. Цель — проверить, способны ли пропущенные дивиденды объяснить отрицательные годы 2018, 2020 и 2024.

Первичные сведения для SBER/03 (обыкновенная акция): [НРД, 26.06.2018 — 12 ₽](https://nsddata.ru/ru/news/view/466666); [годовой отчёт Сбера за 2020 — 05.10.2020 и 18,70 ₽](https://pdf.dfcfw.com/pdf/H2_AN202103241475580432_1.pdf); [НРД, 11.07.2024 — 33,30 ₽](https://nsddata.ru/en/news/view/1156481). Даты — фиксации владельцев, **не** точные даты начала торгов без дивиденда. Отдельная проверка расчётного режима T+ нужна для фактического права.

Для каждой завершённой сделки с входом в указанный год прибавить полный **грязный** дивиденд, если интервал `[entryDay, exitDay]` пересекает окно вокруг даты фиксации ±0, ±7 или ±14 календарных дней. Добавка к процентному результату каждой такой сделки: `100 × dividendPerShare / (entryPrice × 1,0005 × 1,003)`. Сумму считать без налога, задержки выплаты и ограничений реинвестирования, даже для сделок без фактического права на выплату. Это сознательно благоприятная чувствительность, не точная денежная доходность и не воспроизводимый реальный брокерский счёт.

Показать число заведомо начисленных выплат на сделки, долю net-побед и средний net по каждому слабому году для всех трёх окон. Даже если какой-то год станет положительным, не менять правило и не считать гипотезу принятой: остальные годы, GAZP-сигнал без поправки на собственные дивиденды и минутное исполнение остаются отдельными проверками.
