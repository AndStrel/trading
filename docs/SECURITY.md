# Безопасность

## Сейчас

- сервер работает только через локальный `stdio`;
- токен читается из окружения и не выводится;
- реальные заявки отсутствуют на уровне кода;
- счета выбираются через фиксированные роли;
- все MCP-инструменты помечены как read-only;
- сетевой запрос ограничен таймаутом 10 секунд.

## Правила эксплуатации

1. Создавать отдельный токен T-Invest только для чтения.
2. Хранить его в локальном `.env` или хранилище секретов.
3. Никогда не передавать `.env` в AI-контекст.
4. Не включать маржинальную торговлю и короткие позиции на первых этапах.
5. Отзывать токен при подозрении на утечку.

## GitHub Actions

- Для API smoke-теста используется Environment `tinvest-readonly`, а не общий repository secret.
- Secret называется `T_INVEST_READONLY_TOKEN` и содержит отдельный токен только для чтения.
- Workflow запускается только вручную, после environment approval.
- В job всегда загружается `main`, поэтому непроверенный код из ветки или pull request не получает токен.
- GitHub Actions не является средой исполнения торгового MCP и не хранит рабочий токен локального сервера.

## До появления торговли

Обязательны: отдельный токен, песочница, подтверждение каждой заявки, allowlist инструментов, лимиты позиции/сделки/дня, запрет рыночных заявок по умолчанию, idempotency, неизменяемый журнал и kill switch.
