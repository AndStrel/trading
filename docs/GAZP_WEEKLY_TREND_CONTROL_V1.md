# GAZP: контроль того же недельного годового тренда — протокол v1

Правило зафиксировано до расчёта GAZP. Это **один торгуемый инструмент GAZP**, без комбинирования его сделок с SBER. Переносим [прежнее правило SBER](WEEKLY_TREND_V1.md) без изменения параметров на официальный дневной ряд MOEX ISS TQBR/GAZP за 2015–2025 годы (`.trading/gazp-daily-2015-2025.json`, 2827 строк, SHA `d0705203ae7629cc0b919f5b2a6da8b5be333972d8c81aba8bc6d1b13923c261`). Это проверка переносимости механизма, а не независимое доказательство будущей прибыли. 2026 не использовать.

Отбросить выходные сессии для решений. В первый наблюдаемый будний торговый день календарной недели открыть long, если `close` предыдущей будней сессии строго выше `close` 252 будних сессий ранее. Если предыдущая будняя сессия старше 7 календарных дней, вход отменить. Купить по дневному `open`, продать по `open` 20-й следующей будней торговой сессии. До пяти перекрывающихся позиций; на вход не более 1/5 текущего модельного капитала, без плеча, дробные акции. Начало — 1 млн ₽. Выходы прежде входов; открытые на конце 2025 позиции — pending.

Расходы без изменения: комиссия 0,3% на каждую сторону, неблагоприятное проскальзывание 0,05% на сторону, стресс 0,10%. Контроль — вход каждый доступный первый день недели без фильтра тренда, с тем же сроком и расходами. Цена GAZP без дивидендов, налоги, реальные лоты и стакан пока не учитываются; дневной `open` требует минутной сверки.

Показать полный журнал, годы и блоки 2016–2019/2020–2022/2023–2025, net-победы, средний net, PF, результат без пяти лучших, число недель и капитал. Ворота: ≥100 завершённых сделок в ≥50 неделях, ≥51% net-побед, положительный средний net, PF>1, положительная сумма без пяти лучших, положительный результат каждого года и поздних блоков. Отсутствующий год с нулём сделок — пробел доказательств. Даже прохождение не разрешает торговать: нужны дивидендная/минутная сверки и один независимый 2026. Не менять параметры после результата; никаких реальных заявок.
