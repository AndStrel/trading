# Свечные закономерности 2024–2025 v1

Исследование, не заявка. Записано до расчёта. Окно — два последних полных календарных года, которые есть у SBER, GAZP и SBMX: 2024-01-01…2025-12-30. Сессии после 2025-12-30 не используются. 2024 только для поиска и группировки. 2025 только для проверки. Пороги после просмотра 2025 не меняются. Это не продолжение закрытого скальпа.

Тариф `traderBeforeSubscription`. Стресс — комиссия 0,05% и проскальзывание 0,10%. Абонентские 390 ₽ в средний net не входят. Сделка — покупка по `open` дня и продажа по `close` того же дня. Только long.

## Две группы знаков

Знак тела: `U`, если `close >= open`, иначе `D`. Знак шага: `U`, если `close` выше `close` предыдущей сессии, иначе `D`.

Закономерность — три последних завершённых знака перед днём сделки. Восемь комбинаций в каждой группе. День сделки в свой знак не входит.

Группа становится гипотезой только если на 2024 у SBER, GAZP и SBMX одновременно не меньше 20 сделок, доля net-побед не ниже 51% и средний net больше нуля. Иначе группа не проверяется как стратегия.

## Проверка

Отобранная группа допускается, только если на 2025 у каждого из трёх имён не меньше 20 сделок, доля net-побед не ниже 51%, средний net и стресс больше нуля. Одного имени мало. Прохождение не разрешает заявки: дивиденды, налоги, лоты и стакан не включены. Если ни одна группа не проходит 2024, гипотез для 2025 нет.
