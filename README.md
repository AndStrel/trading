# Trading MCP

Безопасный MCP-сервер для анализа российских биржевых инструментов через T-Invest API.

Текущая версия **только читает данные** и рассчитывает торговый план. Она не умеет выставлять, изменять или отменять реальные заявки.

## Что уже есть

- два независимых профиля: `intraday` и `swing`;
- счета, портфель, позиции и остатки;
- поиск инструмента, последние биржевые цены, стакан, статус торгов и исторические свечи;
- расчёт тренда, ATR-волатильности и относительного объёма по полным свечам;
- расчёт размера позиции по риску и стоимости;
- проверка положения стопа и цели для покупки или короткой продажи;
- комиссия полного круга и ожидаемое проскальзывание;
- запрет рекомендации при `reward/risk < 2`;
- тесты, сборка и GitHub Actions.

## Локальный запуск

Требуется Node.js 22+. Токен хранится только в локальном файле `.env`; он уже исключён из Git.

```bash
git clone https://github.com/AndStrel/trading.git
cd trading
node --version
npm ci
cp .env.example .env
chmod 600 .env
```

Заполните в `.env` только `T_INVEST_TOKEN` токеном **только для чтения**. Не передавайте его в чат, issue, commit или скриншот. Затем выполните:

```bash
npm run check
npm run build
npm run smoke:tinvest
chmod 700 scripts/start-local.sh
```

Успешная проверка выведет только `T-Invest read-only authentication smoke test passed`; данные счёта и токен в вывод не попадают.

### Ubuntu и российские сертификаты

На 14 сентября 2026 T-Invest API отдаёт сертификат `*.tbank.ru`, выпущенный `Russian Trusted Sub CA` Минцифры. Если системный `curl` открывает `https://invest-public-api.tbank.ru/rest`, а Node сообщает `SELF_SIGNED_CERT_IN_CHAIN`, включите только в локальном `.env`:

```dotenv
T_INVEST_TRANSPORT=system-curl
```

Этот режим использует установленный в Ubuntu `curl` и его системное хранилище доверенных CA. Проверка TLS остаётся включённой: сервер не передаёт `-k`, не отключает проверку сертификата и принимает только HTTPS. Токен не передаётся в аргументах процесса: на время запроса он записывается в закрытый временный файл, который сразу удаляется.

Подключите MCP-клиент к локальному launcher — он сам найдёт `.env` рядом с проектом, поэтому токена в конфиге нет:

```json
{
  "mcpServers": {
    "trading": {
      "command": "/absolute/path/to/trading/scripts/start-local.sh"
    }
  }
}
```

После первого подключения вызовите `list_accounts`, добавьте идентификаторы счетов в локальный `.env` и перезапустите MCP:

```dotenv
T_INVEST_INTRADAY_ACCOUNT_ID=account-id
T_INVEST_SWING_ACCOUNT_ID=account-id
```

Для локальной отладки можно также запустить `npm run dev` или MCP Inspector:

```bash
npx @modelcontextprotocol/inspector scripts/start-local.sh
```

## Рабочий компьютер

На корпоративном или управляемом устройстве локальный токен потенциально доступен администраторам и защитному ПО. Для этого компьютера используйте только отдельный токен T-Invest без торговых полномочий, храните `.env` с правами `600` и отзывайте токен при смене устройства или подозрении на утечку.

## GitHub Actions

GitHub-hosted runner при проверке T-Invest вернул `SELF_SIGNED_CERT_IN_CHAIN`, поэтому он не подходит для этого токена. Рабочий MCP запускается локально, а не в Actions. Если `T_INVEST_READONLY_TOKEN` уже добавлен в GitHub Environment, удалите его после успешного локального smoke-теста и не запускайте workflow до отдельной настройки доверенной self-hosted среды.

## Инструменты MCP

| Инструмент | Назначение |
|---|---|
| `system_status` | Проверяет конфигурацию без раскрытия секретов |
| `list_accounts` | Показывает доступные брокерские счета |
| `get_portfolio` | Возвращает портфель выбранной стратегии |
| `get_positions` | Возвращает позиции и деньги выбранной стратегии |
| `find_instrument` | Ищет доступную через API бумагу по тикеру, FIGI, ISIN или названию |
| `get_last_prices` | Загружает последние биржевые цены |
| `get_order_book` | Показывает стакан для оценки спреда и ликвидности |
| `get_trading_status` | Проверяет, доступны ли биржевые и API-торги |
| `get_market_snapshot` | Одним вызовом получает цену, стакан и статус торгов |
| `get_candles` | Загружает свечи 1/5/15 минут, час или день |
| `analyze_candles` | Считает тренд, ATR-волатильность и относительный объём без выдачи торгового сигнала |
| `calculate_trade_plan` | Считает лоты, риск, комиссию, проскальзывание и потенциал |

## Границы версии 0.1

- Часть ответов T-Invest пока возвращается почти без преобразования; `analyze_candles` нормализует только свечи.
- Новостной анализ, полноценная карточка сценария, журнал и статистика сделок ещё не реализованы.
- Реальные торговые команды намеренно отсутствуют.
- Это инженерный инструмент анализа, а не обещание доходности и не замена вашему подтверждению сделки.
