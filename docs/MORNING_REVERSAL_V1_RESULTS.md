## Проверенная гипотеза

Будни, решение в 12:00: бумага упала с открытия минимум на 0,5%, но за последние 30 минут восстановилась минимум на 0,1%. Покупка не ранее 12:01, продажа не ранее 17:01. Максимум один вход на тикер в день. SBER и GAZP, без плеча/шорта/переноса через ночь. Полные условия и обработка остановок — в протоколе.

## Что стало с прежним часовым экспериментом

Только пересчёт прежних полных сделок; неполные сигналы остаются отдельным ограничением старого отчёта, модели не переобучались. По основному новому тарифному сценарию средний net logistic: 2024 **−0,720%**, 2025 **−0,642%**; MLP: **−0,710%** и **−0,888%** соответственно. Старые результаты и протокол не переписаны.

## Ограничения и воспроизведение

Проверки: 175 тестов в 35 файлах проходят, в том числе отдельным прогоном на Node 24; typecheck, build и `git diff --check` проходят. Два повторных прогона финального кода дали побайтово одинаковый отчёт. SHA-256 отчёта: `5afeea77975c9fef769ea8a5a45833fa1aeba6611b341436131b6c362fa1b65e`; кода: `b3a9d8e85c0d7bbc9b26ac112eff26cd8ee2ab2d1fbc0ee381d78c2c68887562`; аудита пропусков: `11a046a48e6c77a54c89c749bc2f5576f8f438c97f08a298c9bb21542447b54e`. Добавление защитных проверок после первого прогона не изменило торговые результаты или переоценку старых сделок.

Это доходности отдельных событий до налогов, не доходность капитала. Нет портфельного размера, исторических лотов, оценки вместимости, достоверной MTM-просадки, эмпирически откалиброванного проскальзывания или независимого нового периода. Семантика исполнения при остановке проверена, но это не доказательство, что реальная заявка исполнилась бы по open исторической минуты.

Команды из корня: `npm run build`, `npm run research:gap-audit`, `npm run research:morning-reversal`. Нужны локальная база, замороженный `.trading/hourly-trend-v1.json` и `.trading/gap-reference-times.json`. Новый полный журнал и отдельная переоценка старых сделок: `.trading/morning-reversal-v1.json`. База открывается только для чтения; `.env`/токен не нужны для повторного расчёта.

Решение: к портфельному этапу и реальному исполнению не переходить; не запускать подбор параметров этого v1. Пропуски не доказали наличие потерянной прибыльности, а gross-эффект слишком мал относительно расходов. Следующий эксперимент требует отдельного экономического основания, а не очередного перебора похожих порогов.
