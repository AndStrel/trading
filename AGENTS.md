# Правила работы с репозиторием

- Приоритет: сохранность капитала, проверяемость расчётов, минимальные полномочия.
- Никогда не добавлять токены, account ID, персональные брокерские отчёты и реальные позиции в git.
- LLM не должна самостоятельно считать критичные денежные значения: расчёты выполняются и тестируются в коде.
- Реальные торговые инструменты нельзя добавлять в существующий read-only клиент. Для них нужен отдельный модуль и отдельный токен.
- До подключения исполнения обязательны sandbox, human confirmation, idempotency, audit log, loss limits и kill switch.
- Перед завершением изменения запускать `npm run check` и `npm run build`.
