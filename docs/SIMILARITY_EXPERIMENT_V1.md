# Similarity baseline v1 — протокол до просмотра результатов

Зафиксирован 2026-09-22 после сверки исходных свечей, до расчёта PnL.
Это первичный тест торгового сигнала, не портфельный бэктест и не допуск к реальным сделкам.

- SBER и GAZP, длинные позиции, без подбора параметров. 2023 — первоначальная история; 2024 и уже изученный 2025 — последовательная исследовательская проверка, не новый независимый holdout.
- Используются 10 зафиксированных признаков situation-v2, окно 30 минут, шаг каталога 5 минут. Решения на закрытии минут 10:29, 11:29, …, 16:29 МСК (то есть в 10:30, …, 16:30).
- Для каждого решения: последние 60 наблюдавшихся торговых дат той же бумаги, только строго предыдущие дни. По одному наиболее близкому вектору из каждого дня, затем 20 ближайших дней. Доходность соседа на 60 минут должна быть известна до решения. Минимум 20 разных дней. Никаких исходов текущего/будущих дней в отборе.
- Покупка, если средняя историческая 60-минутная доходность этих соседей строго выше 0,30%. Максимум первый сигнал на тикер в день. Порог один для всех лет и стрессов.
- Вход по открытию следующей минуты, выход по закрытию 60-й минуты после входа. Вся цепочка из 60 свечей должна быть доступна. Пробелы после сигнала регистрируются отдельно; при их наличии итог не является полным тестом, а не получает выдуманную цену исполнения.
- Комиссия и проскальзывание: по 0,05% на сторону каждое (около 0,20% за полный круг). Стресс: комиссия 0,05%, проскальзывание 0,10% на сторону (около 0,30%). Дополнительный стресс 0,40%. Это модель, не измеренные спреды.
- Первый критерий отказа: неположительная средняя net-доходность или profit factor <=1 в любом исследовательском году при базовых расходах/стрессе 0,30%, либо менее 100 исполненных сигналов/50 разных дат суммарно. Проверить также результат без лучшего дня и без лучшего тикера. Если тест провален, не запускать перебор порогов в том же эксперименте.
- Только если первичный тест проходит, следующий этап — фиксированный капитал, целые исторические лоты, одновременные позиции, mark-to-market просадка и блочный bootstrap. До этого суммы процентов по событиям не называются доходностью портфеля, а исторические лоты/календарь не объявляются полностью верифицированными.

Сырые исходники и манифест сверки остаются в `.trading/`. Для GAZP 2025-10-27 нормализованы 64 строки объёма, подтверждённые по OHLC, объёму в лотах и рублёвому обороту независимыми данными Т-Инвест. Ни один день не исключён из-за результата торговли.
