## Что проверяем

Все три уже реализованные стратегии версии 1, без изменения их правил:

- `trend-momentum-v1` — тренд и относительный объём.
- `opening-range-breakout-v1` — первый пробой начального диапазона.
- `vwap-reclaim-v1` — возврат выше растущего VWAP.

Матрица заранее фиксирована: три стратегии × капитал 500/1 000 ₽ × расходы
Investor/public-trader/conditional-003 = **18 отдельных сценариев**.
Это независимые модельные денежные пути, не портфель и не переключение
на исторически лучшую стратегию. Все результаты, включая нулевые и отказавшие,
публикуются вместе. Не ранжировать победителей и не подбирать параметры,
инструмент, период, капитал или тариф после результатов.

## Источник и неизменные правила

Используется уже финализированный публичный SBER/TQBR minute source:
UTC `[2025-08-01T00:00:00Z, 2026-09-27T00:00:00Z)`, лот 1 и модельный шаг
0,01 ₽. Content SHA-256:
`d1189ecfdab756d9d23d06cc3ff5ee0b24e74d4e327b130c95c2a15544ee72ad`.
Это уже изученный период: новая проверка других алгоритмов **не является OOS**.
384 наблюдаемых даты не доказывают полноту биржевого календаря.

Все правила источника, комиссий, целочисленного sizing, cash/risk path,
same-cohort stress и консервативных выходов сохраняются из
[базового протокола](CATALOG_PARITY_REPLAY_V1.md). Новое дополнение меняет
только набор уже существующих алгоритмов, не старый trend-протокол.

- Общий `evaluateTradingSignal`, lookback 360 минут, reference 09:10 МСК.
- Только пять последовательных закрытых минут; следующая minute OPEN —
  синтетический ASK, не стакан/fill. Будущие HIGH/LOW/CLOSE не участвуют в сигнале.
- Trend: исходные SMA20/SMA50, RVOL, stop/target и точные expense gates.
- ORB: первые шесть свечей reference-окна, первый closing breakout,
  крайний срок 11:40 МСК; пересечение с pilot gate не раньше 10:05.
- VWAP: целое reference-окно, минимум 21 закрытая свеча, исходные
  reclaim/rising VWAP/SMA20/RVOL. Цель 4 ATR и стоп 1,5 ATR не растягивать.
- Текущие entry gates, максимум три входа/дату, одна позиция, только long.
- Риск сделки 20 ₽, дневной резерв риска и отрицательные результаты 60 ₽;
  прибыль не восстанавливает риск, пополнений/кредита нет.
- Investor: 0,003 за сторону, без monthly fee. Public Trader: 0,0005
  и модельные 390 ₽/активный календарный месяц. Conditional: 0,0003
  и те же 390 ₽; не подтверждён для пользователя и не production-compatible.
- Проскальзывание base 0,0005/stress 0,001 за сторону; комиссии и
  проскальзывание округляются вверх до копейки. Stress — на тех же сделках.
- Monthly fee до первого исходного входа месяца; нельзя обходить первый
  cash/risk отказ уменьшением лотов, пропуском сделки или будущей прибылью.
- Exact OPEN 18:30, STOP first при двух касаниях, без дополнительной прибыли
  при gap выше цели. Пропуски/STOP_LIMIT gap остаются unresolved.

## Приёмка и пределы вывода

Для каждого сценария отдельно: минимум 100 закрытых сделок/50 дат входа,
минимум 51% строго положительных net-сделок, положительный net после расходов
и обслуживания, положительный результат каждого объявленного периода,
same-cohort stress и исключения пяти лучших, ноль unresolved, выполнимый
base/stress cash/risk path. Пустая выборка — недостаток доказательств, не
доказательство отсутствия прибыли вообще. Номинальный net невыполнимой
выборки не выдаётся за достижимый результат счёта.

Во всех 18 сценариях `admission.allowed=false`, `executableEvidence=false` и
`ordersSubmitted=false`, даже при проходе всех модельных чисел. Для реального
допуска отдельно нужны новый заранее отложенный forward/OOS, реальные
bid/ask/depth/fill, полный sandbox-цикл и точная cash-сверка, плюс отдельный
реальный исполнитель. Приглашения, сроки и желание начать сегодня не заменяют
эти условия. Торговые методы в read-only клиент не добавляются.

## Воспроизводимый запуск

```sh
npm run build
npm run backtest:catalog -- --database /absolute/path/history.sqlite --strategy all --cost all
```

Default без `--strategy` остаётся старым trend-only replay. Допускаются только
текущие catalog IDs или `all`; произвольные алгоритмы и retuning flags запрещены.
Каждый scenario содержит явные `strategyId`/`strategyVersion`. Источник
загружается один раз, а деньги/риски/резервы каждого сценария независимы.

Реальный прогон выполняется локально в контейнере без сети, `.env`, токенов и
брокерских клиентов, с immutable read-only mount только нового source directory.
До/после сверяются source SHA и отсутствие sidecars. Полные результаты остаются
в ignored `.trading`; synthetic contracts/полный check/build и независимое
ревью проверяют реализацию, но не являются рыночной прибыльностью.
