# Однодневный пропуск IMOEX 25.02.2008: протокол чувствительности

Зафиксировано до просмотра торговых исходов. Предыдущая поправка к историческому протоколу имеет SHA `71da5229fb17ddcfa6b040fc90d584612a5abcf4f7132fb6d5a345364a83735e`. Проверка календарей официальных дневных рядов 2007–2014 нашла ровно одну дату SBER без IMOEX: **25.02.2008**. Запросы MOEX ISS к свечам IMOEX и MICEXINDEXCF и к исторической таблице индекса за эту дату вернули пустые данные. Значение индекса нельзя выдавать за наблюдавшееся.

Запустить **оба** сценария, не выбирая выгодный после результата:

1. `carry-forward`: только для 25.02.2008 создать синтетическую запись IMOEX с `open=high=low=close` равным `close` предыдущей доступной будней свечи IMOEX; пометить дату как imputed. Все фактические SBER/GAZP сессии сохранить. Это означает предположение «последнее известное значение индекса не изменилось».
2. `omit-day`: исключить 25.02.2008 одновременно из SBER и GAZP, оставить официальный IMOEX без добавления. Это меняет счётчик 20/252 сессий на один день; трактовать как отдельную чувствительность, не как точную модель торгов.

Оба сценария используют все остальные доступные даты и ровно те же торговые правила и расходы [исходного протокола](WEEKLY_MARKET_REGIME_PRE2015_VALIDATION.md). Публиковать число сделок, годы и разницу результатов между сценариями. Исторический кандидат может считаться устойчивым к этой дыре только если **оба** сценария проходят фиксированные ворота; один удачный вариант недостаточен. Никакие другие пропуски не заполнять: при появлении новой несостыковки расчёт остановить.
