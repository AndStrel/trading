# BR 11:01-entry oracle ceiling — exploratory diagnostic

This calculation is an unattainable upper bound, **not** a strategy, signal or trade recommendation. The 2026 BR archive and first-hour rule have already been studied; no part of this diagnostic is an independent validation. Its sole question is whether a fixed 11:01 MSK entry has enough later same-day price range to overcome the current Investor futures cost model even if the trader could know the future best minute high/low.

Use the locked MOEX ISS RFUD exact-contract BR one-minute archive dated 2026-03-23 through 2026-09-25, source-report SHA-256 `d8721ce74334619fc1c7f6f960a85d6e77e7ddcb050958163a9b9d8081caf57a`. Exclude the preidentified special-session dates 2026-05-01 and 2026-06-12. Require the exact 11:01 entry open and **every** minute from 11:02 through 16:55; incomplete dates are counted as missing, not optimistically scored. For each complete date, separately consider one long and one short entry at the same 11:01 print. The clairvoyant long sells at the highest later one-minute `high`; the clairvoyant short buys at the lowest later `low`. No stop, target or parameter choice is involved.

Apply 0.10% broker commission per side plus 0.05% adverse execution per side (base), and repeat with 0.10% adverse execution per side (stress), using the existing deterministic `siTradeReturn` accounting on BR quote prices. Report complete/missing counts, net-positive oracle days and mean oracle return for both fixed directions. A 51% oracle fraction is only a **necessary** screen for a fixed-entry strategy that trades every complete date, not sufficient evidence: true exits cannot know future extrema or necessarily fill there. BR is quoted in USD/barrel; quote-normalized returns do not establish exact RUB P&L, margin sufficiency, fee rounding or taxes. No broker calls or orders.
