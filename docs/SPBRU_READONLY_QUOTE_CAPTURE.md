# TMON@/SPBRU local read-only quote capture

This optional container samples the broker's **TMON@/SPBRU** unary order book, UID `498ec3ff-ef27-4729-9703-a5aac48d5789`. It does not use the MOEX/TQBR route. It requests only `MarketDataService/GetOrderBook` (depth five) and `GetTradingStatus`, never account data or order methods. The image contains the extra CA certificates **only inside the container**; TLS verification stays enabled. The container has a read-only filesystem, dropped Linux capabilities, no privilege escalation, one quote-output bind mount, and a single token secret mount. This limits exposure but is not a proof against compromise. Its outbound network is not restricted to one hostname by Docker Compose; the application hardcodes the official T-Invest REST base URL.

The operator must create a **dedicated read-only T-Invest API token** — never a full-access or transfer token — and save it as one line at `.trading/secrets/tinvest-readonly-token` with host permission `0600`. Do not send the token in chat, put it in `.env`, or paste it into a shell command that may enter history. The project `.trading/` directory is ignored by Git. The agent must not read or print this file. T-Invest states that a read-only token cannot submit trading orders: [official token documentation](https://developer.tbank.ru/invest/intro/intro/token).

After the operator supplies the secret, start locally with `docker compose --profile spbru-quotes build spbru-quote-capture` and `docker compose --profile spbru-quotes up -d --no-deps spbru-quote-capture`. Stop with `docker compose --profile spbru-quotes stop spbru-quote-capture`. The service is **not started merely by building it**. It does not inherit the project's `.env` or the separate trading token. Do not start it if the secret's read-only permission has not been verified by the operator.

Setup checkpoint, 28 September 2026: the image built successfully with TLS verification enabled and the extra CA certificates confined to that image. A disposable, non-secret placeholder confirmed that UID 1000 inside the container can read the secret mount; the placeholder was removed. No real token file was present, no broker request was made by the container, and the service was left stopped. A live accepted-sample check remains pending the operator's dedicated read-only token.

It attempts one sample every five minutes on every calendar day from 10:05 through 22:55 MSK, at most 155 slots/day. Actual trading status is checked each time; holidays and breaks become rejected observations, not invented quotes. Each attempt is appended to ignored `.trading/quotes-spbru/tmon-spbru-attempts.jsonl`: the Moscow-time slot, start/finish timestamps in UTC, accepted/rejected/request-error result, and only for accepted quotes a sanitized five-level bid/ask sample with the exchange order-book timestamp. The token, account IDs, raw API errors and order payloads are never written. Stale (>15 seconds), crossed, malformed, wrong-UID, non-RUB or non-normal-trading books are rejected. Repeated identical books remain repeated observations, not independent price events.

After observations exist, run `npm run build` and `node dist/research-spbru-quote-quality.js` for a local quality report at `.trading/quotes-spbru/tmon-spbru-quality.json`. It validates scheduled slots and timestamps, separates requests, accepted quotes, repeated exact books and repeated top-of-book price/depth states, and reports spread and book-age distributions. It does not infer a fill probability. No report can yet be produced because the dedicated token and hence quote attempts are absent.

This is **observation**, not fill evidence. A quoted size may vanish, a delay can invalidate the price, and the queue position is unknown. Do not infer an execution probability or allow orders from a small sample. For a useful quality audit, require many sessions and show accepted/attempted counts, age distribution, spread distribution by hour and day, depth at the intended size, quote persistence, and missing periods. Never merge these samples with MOEX/TQBR quotes as if they were one venue.
