# TMON 2026 same-day print coverage — timestamps first

This is a data-availability check, not a profitability test or order authorization. Fix the period **2026-01-01 through 2026-09-25**, ordinary weekdays only, before reading any 2026 TMON prices. Query public MOEX ISS one-minute trade candles between 10:00 and 17:00 MSK. Use TQTF before **2026-06-22** and TQBR on/after that date, following the [MOEX board migration notice](https://www.moex.com/n99295). Preserve raw responses with hashes; reject malformed and duplicate timestamps. No prices or returns are used for the coverage decision.

Carry forward the 2025 fixed windows **only for coverage**: first entry print 10:01–10:03, first exit print 16:55–17:00. Report all weekdays, active dates, complete 421-minute dates, entry-present dates, exit-present dates, both-present dates, cancellations and entered dates lacking a printed exit. Do not silently select only paired days. If at least 100 dates have both prints and no entered date lacks an exit print, the trade-print source can support a separate, explicitly labeled exploratory price test; it still cannot prove quotes or fills. Otherwise prioritize forward bid/ask observations. The incomplete 2025 TMON screen does not become independently validated merely by inspecting 2026.
