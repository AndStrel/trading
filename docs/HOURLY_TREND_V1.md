# Hourly trend v1 — протокол до результатов

Дата: 2026-09-22. Исследовательское сравнение, не рекомендации и не запуск сделок.

## Данные и время

SBER/GAZP, сверенные минутные архивы 2023–2025. Только наблюдаемые даты, решения в 12:00–17:00 МСК каждый час. Для признаков нужны все 120 минут перед решением; отсутствие любой минуты блокирует решение и учитывается в отчёте. Календарь полностью не аттестован.

Шесть признаков: доходность последнего и предыдущего часа (close/open − 1); high/low − 1 каждого часа; log((объём последнего часа + 1)/(объём предыдущего + 1)); положение последнего close в диапазоне последних двух часов (0,5 при нулевом диапазоне). Признаки используют только завершённые минуты, никаких абсолютных цен и идентификатора тикера.

Long/cash: отдельный часовой вход по open минуты через одну минуту после решения, выход по close 60-й минуты удержания. Например: решение 12:00, вход 12:01, выход на закрытии 13:00, результат известен в 13:01. В будущем окне нужны все 60 минут. Пропавший исход нельзя молча вычеркнуть после появления сигнала: он блокирует приёмку модели. Метка обучения — положительная gross-доходность этого окна, а не направление уже прошедшего часа.

## Сравниваемые модели (без подбора)

1. Контроль always-long: каждый доступный час.
2. Простое трендовое правило: положительна доходность обоих прошлых часов.
3. Логистическая регрессия, вероятность роста > 0,55.
4. Небольшая нейросеть 6→6 tanh→1 sigmoid, тот же порог > 0,55.

Для обеих обучаемых моделей: pooled SBER/GAZP, без балансировки классов, standard scaler только по train (нулевое стандартное отклонение заменяется 1), значения ограничены ±5 после нормализации. Full-batch gradient descent, binary cross-entropy, 300 эпох, learning rate 0,05, L2 0,001 только весов (не bias). Logistic стартует с нулей; MLP детерминированный LCG seed 42, веса равномерно ±0,2, bias 0. Нет поиска архитектур, seed, порогов или выбора лучшей эпохи по проверяемому году.

2024 проверяется после обучения только на 2023; 2025 — после нового обучения на 2023–2024. До обучения доступны только завершённые исходы раньше 1 января проверяемого года. Минимум 200 обучающих примеров и оба класса, иначе ошибка. Обе модели запускаются независимо от результата baseline для честного сравнения. 2023–2025 уже исследованы: это хронологическая проверка, **не новый независимый holdout**.

## Расходы и критерии

Комиссия 0,05% на сторону, проскальзывание 0,05% на сторону; стресс проскальзывания 0,10%, дополнительный 0,15% (около 0,20/0,30/0,40% полного круга). Учитываются мультипликативно по фактическим модельным ценам входа/выхода. Это допущения, не измеренные спреды или брокерский тариф.

Для допуска к дальнейшему портфельному тесту требуются одновременно: отсутствие неполных сигналов; минимум 100 сигналов и 50 разных дат суммарно; в каждом проверяемом году при базовых расходах и стрессе 0,30% средний net > 0, profit factor > 1, положительный результат без лучшего дня и без лучшего тикера. При отсутствии убытков profit factor не вычисляется, но критерий отношения считается пройденным только при положительной прибыли. Контроли служат сравнением, не кандидатами на автоматическую торговлю.

Показатели — доходности отдельных событий, не портфеля. Позиции условно нормированы: нет кредита/шорта, но размер капитала, исторические лоты, одновременные позиции, MTM-просадка и лимиты риска требуют отдельного этапа. Даже прохождение первичного теста не разрешает реальные сделки. После отказа не менять правила этого v1. Модели, прогнозы, исключения, хеши исходников/протокола и результаты сохраняются локально в `.trading/hourly-trend-v1.json`.
