# Trading bot

Бот для анализа инструментов Мосбиржи через T-Invest, выбора торгового подхода и получения проверяемых рекомендаций в Telegram и Mini App. Расчёт позиции учитывает лот, риск, комиссии, проскальзывание и актуальный стакан; кандидат сохраняется в локальном SQLite-журнале.

## Быстрый запуск

Нужны Node.js 22+, Docker с Compose и отдельные токены T-Invest только для чтения и Telegram. Все проекты можно держать в `~/dev`.

```bash
git clone https://github.com/AndStrel/trading.git ~/dev/trading
cd ~/dev/trading
npm ci
npm run setup
```

Заполните `.env` локальным редактором. Минимальные поля — `T_INVEST_TOKEN` и `TELEGRAM_BOT_TOKEN`. Затем:

```bash
npm run doctor
npm run deploy
```

Первый `/start` в Telegram покажет ваш chat ID. Сохраните его в `TELEGRAM_ALLOWED_CHAT_IDS` и повторите `npm run deploy`. Подробная инструкция, кнопки, Mini App и решение типовых проблем: [QUICKSTART](docs/QUICKSTART.md).

`setup` создаёт `.env` только при его отсутствии, устанавливает права `600` и готовит приватные каталоги данных. Существующие токены и настройки сохраняются. `doctor` проверяет локальную конфигурацию теми же правилами, что сервис; он не обращается к сети и не выводит значения токенов, счетов или chat ID.

## Торговая логика

Сканер получает полные свечи и выбирает инструменты из настроенной вселенной. В Mini App можно выбрать торговую стратегию; смена выбора аннулирует прежние рекомендации, чтобы карточка от старого подхода не стала основанием новой сделки. Рекомендация объясняет подходящий инструмент, сигнал и причины допуска либо отказа. Расчёт риска и денег выполняется кодом.

Доступные подходы: `trend-momentum-v1`, `opening-range-breakout-v1` и `vwap-reclaim-v1`. Параметры задаются в `.env.example`; алгоритмы и область их применения описаны в [каталоге стратегий](docs/STRATEGIES.md).

По умолчанию `T_INVEST_EXECUTION_MODE=disabled`. Реализованное брокерское исполнение — подтверждённые сделки в отдельной песочнице; оно требует подготовленного счёта, журналирования, лимитов и управления kill switch. Подготовка реального дневного профиля и наличие live-токена не включают реальные заявки. Стратегии — набор технических правил; доказанного обещания доходности или 51% net-побед у них нет. Состояния исполнения и приёмка: [SANDBOX_EXECUTION](docs/SANDBOX_EXECUTION.md), [SANDBOX_VTBR_ACCEPTANCE](docs/SANDBOX_VTBR_ACCEPTANCE.md).

## Работа с сервисом

```bash
npm run status
npm run logs
npm run stop
```

Журнал и рыночная история хранятся в Docker volume `trading-journal`. Compose публикует Mini App только на `127.0.0.1:8088`; внешний HTTPS обеспечивает отдельный reverse proxy. Цепочка CA T-Invest устанавливается внутри образа, системное доверие компьютера не меняется. TLS-проверка остаётся включённой.

Для MCP-клиента вместо контейнера используется [локальный launcher](scripts/start-local.sh); его описание есть в [QUICKSTART](docs/QUICKSTART.md#mcp-и-локальный-процесс).
